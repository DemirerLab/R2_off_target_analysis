# R2_off_target_analysis
The workflow outlined here is used for analyzing illumina sequencing data generated using the tagmentation-based tag integration site sequencing (TTISS) method initially developed by [Schmid-Burgk _et al_., 2020](https://doi.org/10.1016/j.molcel.2020.02.023) and modified by [Edmonds _et al_., 2025](https://doi.org/10.1038/s41467-025-61321-z) for R2 retrotransposon insertion site analysis.
